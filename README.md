# Getränke-Tracker – Home-Assistant-Add-on

Add-on-Repository für den Getränke-Tracker (Strichliste für den Kühlschrank).

**Nicht von Hand ändern:** Der Inhalt wird bei jedem Push auf `main` im
App-Repo `lsvllr/getraenke-tracker` (Ordner `ha-addon/`) per GitHub Action
hierher kopiert; die Version setzt die Action.

## Installation

Home Assistant → Einstellungen → Apps → Store → ⋮ → Repositories →
`https://github.com/lsvllr/getraenke-addon` hinzufügen → „Getränke-Tracker“
installieren.
